Let a sloth tidy your Downloads folder.

sloth-tidy sorts messy files into the right folders using an open-weight AI model that runs on your own computer. Your documents never leave your laptop.

View the code on GitHub How to run it

What it does

Sorts and renames

Reads the first page of PDFs and text files, picks a folder (Uni, Receipts, Travel…) and gives each file a readable name.

Offers reminders

Spots a future date in a flight ticket or deadline and asks if you want a calendar reminder. Nothing is added without your yes.

Finds duplicates

Identical files are detected and you choose which copy to keep. The other one moves to a Duplicates folder. Nothing is deleted.

Easy to undo

It only shows what it would do until you say so, never overwrites a file, and one command reverts the last run.

Why open-source AI?

  • Private. Receipts, tickets and university documents stay on your machine. No server you do not control.
  • Free and offline. After a one-time model download it costs nothing and works without internet.
  • Swappable. Do not like how one model sorts? Change one option and try another, like Gemma or Qwen.

Try it

  1. Install Ollama and download a model: 
    ollama pull gemma3:4b
  2. Get the code and install the two Python libraries: 
    git clone https://github.com/SarpDoruk06/sloth-tidy
cd YOUR-REPO
pip install -r requirements.txt
  3. Do a dry run first. It only prints what would happen: 
    python sloth_tidy.py ~/Downloads
  4. Happy with it? Add --apply. Changed your mind? Use --undo.

Honest limits

Small models sometimes pick the wrong folder or misread a date, which is why there is a dry run, an undo, and a confirmation before any reminder is created. Scanned PDFs without text can only be judged by their file name.
